This is my personal portfolio website built with GitHub Pages.

The project was initially inspired by tutorials from Alex The Analyst (https://youtu.be/ocdwh0KYeUs?si=Rf8X7jaZgx6GhSxy).
Due to later GitHub Pages updates, the original setup required modification.
To resolve this, I added a `.nojekyll` file to the repository to ensure GitHub Pages would correctly serve the static HTML/CSS files without Jekyll processing.

Built using an HTML5 UP template.
